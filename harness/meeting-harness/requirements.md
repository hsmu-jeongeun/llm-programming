# 회의록 할 일 추출기 요구사항

입력은 항상 Python 문자열이다. 자연어 추론 없이 `할 일:` 접두사가 있는 줄만 처리한다.

1. 빈 문자열과 공백만 있는 입력은 예외 없이 빈 리스트 `[]`를 반환한다.
2. 각 줄의 앞뒤 공백을 제거한 뒤 `할 일:`로 시작하는지 확인한다.
3. 첫 번째 콜론 뒤 작업 내용의 앞뒤 공백을 제거한다.
4. 작업 내용이 비어 있으면 목록에 넣지 않는다.
5. 다른 줄은 무시한다. 입력 순서와 작업 내용 안의 콜론은 유지한다.
6. 공개 함수 이름 `extract_actions(text)`와 리스트 반환 형식을 유지한다.

수정 대상은 `src/actions.py`이다. 테스트·요구사항·demo.py는 수정하지 않는다.
외부 패키지와 LLM API는 사용하지 않는다.
